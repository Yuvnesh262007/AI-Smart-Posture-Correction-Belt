# CAD and enclosure design

This directory contains the final CAD exports identified in the project workspace.

## Included exports

- STEP: editable solid-model exchange files for the main base, main lid, battery cradle,
  battery lid and motor mount.
- STL: print-oriented mesh exports for the same five parts.
- GLB: complete assembly and exploded assembly visualisations.

## Design notes from the project CAD review

- Main pod nominal envelope: 68 x 82 x 21 mm.
- Battery pod nominal envelope: 52 x 36 x 14.5 mm.
- Motor mount nominal envelope: 22 x 18 x 6.5 mm; motor pocket approximately 9.2 mm diameter.
- PETG was the recommended print material.
- Suggested starting print settings: 0.2 mm layer height, 3–4 walls and 20–30% infill.

These are design/review dimensions, not a substitute for checking actual component fit.
The project notes recommend a low-cost fit/test print and checking the USB-C and switch
openings against the physical hardware. The prototype was USB-powered at the time of
project documentation; the CAD battery pod does not mean battery operation was completed.
